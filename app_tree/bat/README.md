# bat

The launchers of this project: `RUN.bat` (the Run button), `DEBUG.bat`, `COMMIT.bat`, `PUSH.bat`, `COMMIT_PUSH.bat`. A launcher stays dumb: run the program, stop on error, nothing else. `RUN.bat` and `DEBUG.bat` here are placeholders: put this project's start command in them.

`RUN.bat` runs `app\parse_Python.py` with what you give it. `RUN_TESTS.bat` runs the tests. `PYPARSE.bat` is the old launcher (a path that only worked from one folder): you called it a throwaway; delete it when you like.
