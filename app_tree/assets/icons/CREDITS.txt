CREDITS for the icons in this folder
====================================
Each program icon here is a white glyph on a colored rounded square, saved as NAME.svg (the picture) and NAME.ico (16 to 256 px, what Windows uses).
Zygote draws the tile; the glyph is the part that comes from an icon pack. This file travels with the icons into every project (Project > New copies the folder).
