# assets/icons/
The project's icons. `zygote.png` is the source picture; `zygote.ico` (16 to 256 px) is what windows and the project's shortcut use.
Z 2.19.20: a set of colored program icons (`NAME.svg` + `NAME.ico`), the folder pictures Zygote draws (`*.png`) and `CREDITS.txt` (where each one comes from and its license).
Project > New copies this whole folder into the new project's own `app_tree\assets\icons`, and Browse in Project settings opens there.
