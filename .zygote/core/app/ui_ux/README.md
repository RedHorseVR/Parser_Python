# app/ui_ux/
Everything the user sees and touches, in Python with Qt (PySide6). `main_window.py` is the window: toolbar of real buttons, the version/date stack top-right, folder tree left, icon view right, log line; the whole window takes dropped ZIPs and folders. `dialogs.py` holds the open-project dialog (a drop box plus a folder picker) and the confirmation dialog. `theme.py` holds every color, `zoom.py` the per-panel Ctrl+wheel zoom, `models.py` the file model that draws protected folders blue. The icon view sits under a title bar naming the folder shown. The icon lives in `assets\icons\zygote.ico` (windows and shortcuts). `cli.py` draws and handles the two console buttons, `help_window.py` shows a help page inside the window. `panels.py` is the titled panel (a title bar over a view; the Sort and View lists sit in the bar over the folder view). One style block, one rule per selector. `code_window.py` (Z 2.13.0): the read-only code window, tabs with line numbers, red-circle breakpoints, an arrow on the line where the debugger stopped. `debug_control.py`: the one class behind the debug toolbar buttons, the Debug menu and the code window; it types to the debugger in the Console and reads where it stopped from its output.
