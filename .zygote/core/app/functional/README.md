# app/functional/
What Zygote does, apart from how it looks. `core.py` (standard library; fully tested): a project's version and when it changed, its name and record (`user\zygote.json`), folder rename, checking and unpacking a dropped build ZIP with a snapshot of every drop in the zip folder (`zip\undo\`) and reverting to any of them, making a ZIP into `zip\<VERSION>.zip`, handing a file to Windows, stamping the project shortcut (pywin32). It draws nothing. The window asks it; it answers or raises `ZygoteError` with a plain message. `debugger.py` (Z 2.13.0, plain Python, no Qt): language bundles (`.zygote\\language\\<name>\\bundle.json`, copied from the shelf `.zygote\\assets\\language` only on request), breakpoints that mirror the project tree with a fingerprint per file, and `PositionReader` (where the debugger stopped, read from its own output).
