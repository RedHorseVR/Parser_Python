# .zygote

The machine's side of this project, the way Git keeps its things in `.git`: bin, config, core (the project's copy of Zygote), credentials, env, logs, user. What supports the app (architecture, assets, bat, help, language, notes, setup, tests, tools, utils) lives in `app_tree`, next to `app`. `zip\` (the ZIPs Zygote makes) and `START_HERE.md` stay at the top.
